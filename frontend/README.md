# Turbolehe Frontend (Next.js)

Application React/Next.js moderne pour Turbolehe OSINT.

## Démarrage rapide

```bash
# Installer les dépendances
npm install

# Démarrer en développement
npm run dev

# Construire pour la production
npm run build

# Démarrer en production
npm start
```

## Technologies utilisées

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- React Query
- Axios
